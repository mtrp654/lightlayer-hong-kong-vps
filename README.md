## 香港这条线到底走什么路由，怎么自己验

我查到的 LightLayer 公开页面按 Global、Standard、Premium 分档，没有直接给香港机房标注 CN2 GIA 字样。有第三方汇总文章称香港的 CN2 GIA 回程到内地延迟明显低于普通 BGP，这条属于第三方说法，官方没有对应标注，别当成已确认的事实。

能不能自己验？能，而且比看宣传页靠谱。拿到机器后跑一遍回程路由，看每一跳的 AS 号：

- **AS4809** 是中国电信 CN2，回程一路都是 4809，才叫 CN2 线路。
- **AS4134** 是电信 163 骨干，出现它就说明后半段走的是普通线路。
- **AS4837** 是联通骨干，**AS9808 / AS56040** 是移动 CMI 与省网。

这套方法不吃亏。有测评机构测过一家官网写“优质 BGP”的香港商家，实测三网回程是联通 4837 加移动 CMI，根本不是 CN2。另一家宣称“三网回程全 CN2 GIA”，自家贴出来的 trace 里却出现了 AS4837。商家给线路起的名字是营销语言，AS 号是网络事实。

还有一件事比路由更容易被忽略：测试时段。第三方对另一家香港 BGP 商家的同一台机器做过昼夜对照，中午全国平均 44ms，晚上 76ms，电信从 43ms 变成 81ms，联通从 37ms 变成 100ms。所以你在测评文章里看到的 40ms 出头，很可能是中午的数字。拿到机器后在 20:00–23:00 重新 ping 一遍，那个数才是你每天要用的数。

## 常见问题

**晚高峰会不会掉速？** 没有 LightLayer 香港机房的公开晚高峰数据，我不编。判断方法在上文：晚上 8 点到 11 点重测一遍延迟和丢包，跟白天数字对比。第三方对同类香港 BGP 机器的对照是中午 44ms、晚上 76ms，掉三成是常态。

**要不要开 BBR？** 10Mbps 端口本身不宽，BBR 的收益主要在长肥管道上，家宽到香港这种链路正好属于这类。有实测在 100M 电信家宽上传同一台香港机器，不开 BBR 下载不到 1Mbps，开了约 10Mbps，差一个数量级。LightLayer 是否默认开启我没查到，进系统跑 `sysctl net.ipv4.tcp_congestion_control`，不是 bbr 就开。

**能解锁 Netflix 吗？** 香港年付档标的是非原生 IPv4，解锁能力不作保证，别为这个理由下单。

**能装 Windows 吗？** 公开资料没写。HHOST 那边明确支持 Linux 和 Windows 任选，LightLayer 这边要开工单确认。

**25 端口能出站吗？** 没查到相关说明。要发信的，下单前先问，别等开通了才发现被封。

**月付还是年付？** 新用户先月付跑一周，验完晚高峰再决定要不要压年付。年付省下来的钱，抵不上买错机房的损失。
